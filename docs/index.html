Quick Start

Install once. Connect your agent.


$

Then run clawdcursor consent --accept. On macOS also run clawdcursor grant. To update: npm i -g clawdcursor@latest (clawdcursor update is planned for 2.1).

Claude Code: install the plugin instead, with claude plugin marketplace add AmrDab/clawdcursor then claude plugin install clawdcursor@clawdcursor. Claude Desktop: open the .mcpb extension from the latest GitHub release; no Node.js needed.

Connect

How will your agent talk to it?

Same tools over two transports. clawdcursor never runs a model: your agent's host brings it.

clawdcursor mcp recommended

Your agent's host starts clawdcursor over stdio. No daemon, no port. Config shapes for Codex, VS Code, Zed and opencode are in the README.

How it works

Blind first.

The tree, then text, then OCR. A screenshot last. Your agent makes every call; clawdcursor carries it out.

1 Read

Text, not pixels

read_tree lists a window's elements by name. copy_all_text gives a page's exact text. ocr reads the screen when the tree is empty. A screenshot is the last resort.

→

2 Act by name

Coordinates are the fallback

invoke clicks an element by name and set_value fills a field. smart_click finds a visible label by OCR. Keys are OS-aware: mod is Cmd on macOS, Ctrl elsewhere.

→

3 Check

confirmed · unverified · refused · failed

Every result ends with a status line. Pass expect and the call re-reads the screen, reporting a DEVIATION if the state is not there.

Leaner than computer use.

Features

Any OS. Any model.

💻

Cross-platform

Windows x64/ARM64 · macOS 12+ · Linux X11/Wayland

⌨️

OS-aware keys

The agent is told which OS it is on. mod is Cmd on macOS and Ctrl elsewhere, and named shortcuts are offered only for this OS.

📦

batch: one round-trip

Run a known sequence of tool calls in one call. Each step is refused exactly as a direct call would be.

⏸️

Pauses for you

At a sign-in, 2FA code or CAPTCHA the agent pauses instead of guessing. The prompt turns blue; click Resume and it carries on, or "Something else" to type it an answer.

🟠

Always visible

While an agent drives, a pill says what it is doing and a thin amber outline marks the window in use, on Windows, macOS and Linux. Press Stop on the pill to stop.

🍎

Fast on macOS

A native accessibility helper: 20 windows listed in 0.3 s, a window's tree read in 0.06–0.2 s.

Safety

What protects you.

clawdcursor runs with your own OS permissions and does not decide what your agent may do. Since 2.0 there is no policy gate. These hold for every call:

⏹️

Stop

Press Stop on the pill or run clawdcursor stop. Every clawdcursor process stops, a running batch included, and stays stopped across restarts until you resume.

🟦

The pause card

While the agent waits for you, no other tool call runs. Only you can answer the card; the agent cannot click it or the pill.

💬

No stray input

Input is refused when the window in front is an AI assistant the agent did not focus on purpose, or is no longer the window it was working in.

🔒

Keys never sent

A short per-OS list that locks the machine or ends the session, such as Win+L, Ctrl+Alt+Del and Cmd+Shift+Q. Every other shortcut is allowed.

🔑

Local, with a token

The HTTP server binds 127.0.0.1 only and requires a bearer token. The stdio server opens no port. No telemetry.

📄

Screen text is data

Page text, OCR and the clipboard reach the agent wrapped as untrusted content that cannot close its own wrapper.

What is not enforced. Approval before an action is your MCP host's job: the tools carry read-only and destructive annotations for hosts that prompt. If your host auto-approves tool calls, nothing asks before the agent sends, deletes or pays. For agents you do not fully trust, or for unattended runs, use a host with approval prompts. An opt-in confirm mode is planned for 2.1 (#373). The full threat model is in SECURITY.md.

2.0.0

What changed, and what is next.

2.0.0 is a breaking release. It was first published as 1.6.0 and renumbered to follow semver; 1.6.0 is deprecated on npm.

🧰

A tool layer

The built-in agent loop, the task tool, clawdcursor task and every provider, model and API-key setting are gone. Your agent drives the six tools.

🚧

No policy gate

Tiers, "confirm" and blocked labels are removed: a click by coordinates went around them. The protections above replace them.

🧭

CLI Every command › For humans diagnosing an install. Agents connect via MCP. 
# Install & setup
clawdcursor consent          # one-time desktop-control authorization (always required)
clawdcursor grant            # macOS only: Accessibility + Screen Recording prompts. MCP setup ends here.
clawdcursor doctor           # diagnose the install: version, consent, screen capture, accessibility, permissions
clawdcursor status           # readiness check (consent, permissions)
clawdcursor versions         # every installed copy and its version
clawdcursor register-skill   # register the usage skill in detected agents again

# Run
clawdcursor mcp              # stdio MCP server; your agent's host starts it
clawdcursor mcp --compact    # same, with the 6 compact tools (recommended)
clawdcursor agent            # HTTP MCP server at 127.0.0.1:3847/mcp (--compact, --port, --no-vision)
clawdcursor stop             # stop every running instance; agents stay stopped until resume
clawdcursor resume           # continue a paused task, or give control back after a stop (--end to end the task)
clawdcursor report           # send a redacted report of the last session, after a preview
clawdcursor uninstall        # remove all clawdcursor config and data
